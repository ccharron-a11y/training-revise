# QA/QC Field Documentation Training (SCORM 1.2)

Litmos-authored SCORM 1.2 course, expanded with new content on fact-based issue documentation.

- `scorm/` – unzipped course. All content lives in `scorm/data/en_US/data.xml`.
- `dist/QAQC_Field_Documentation_Training_SCORM12.zip` – upload this to the LMS.
- `build.sh` – re-zips `scorm/` into `dist/` after any edit.
- `tools/expand_content.py` – script that generated the expansion from the original (baseline) `data.xml`.

## Course outline (★ = new page)

1. Welcome (updated)
2. Commissioning Fundamentals and Pre-Inspection (added "Check for Changes" step)
3. Platform Workflows and Checklist Execution
4. ★ Facts, Not Opinions – the Fact Test; opinion vs. fact examples; labeling Observations and Recommendations
5. ★ Finding and Citing the Requirement – document sources, order of precedence, anatomy of a spec citation
6. ★ Writing the Issue Statement: Not IAW / Contrary To – the issue formula and phrase guide
7. Rigorous Issue Documentation
8. ★ Creating and Cross-Referencing Issues – search first, required fields, related/repeat/duplicate/RFI references
9. ★ Defining the Solution – compliance end state, what vs. how, unclear/conflicting/silent documents
10. Issue Classification and the Resolution Lifecycle
11. ★ Bring Your References. Don't Rush. – reference pack, field pause, interactive readiness checklist
12. Field Conflict Management and Professionalism (added pushback protocol and phrasing table)
13. ★ Practice: Rewrite the Issue – four scenarios
14. ★ Summary: Your Field Pocket Guide

Spec section, paragraph and sheet numbers in the examples are illustrative; the course tells learners so.

Note: this package was edited outside the Litmos authoring tool. It runs in any SCORM 1.2 LMS, but
re-importing it into the authoring tool for further visual editing is not guaranteed.
